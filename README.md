1. Які дані використовуються

Проєкт використовує історичні метеорологічні дані, отримані з відкритого API **Open-Meteo (Archive API)**.

Основні параметри (Features):

`temperature_2m_max`: Максимальна температура повітря за добу.
`temperature_2m_min`: Мінімальна температура повітря за добу.
`windspeed_10m_max`: Максимальна швидкість вітру.
`precipitation_sum`: Сумарна кількість опадів (використовується для створення цільової мітки).

Цільова змінна (Target):

`is_precip`: Бінарний показник (0 або 1), де 1 означає наявність опадів (> 0 мм). Модель навчається передбачати цей показник на наступний день (`target_next_day`).


2. Яка модель використовується

Ви обрали Random Forest Classifier (Випадковий ліс) з бібліотеки `scikit-learn`.

* Чому це хороший вибір* Ця модель стійка до викидів у даних, добре працює з нелінійними залежностями та дозволяє оцінити «важливість ознак» (Feature Importance), що ви й візуалізуєте в кінці.
* Параметри: Використовується ансамбль зі 100 дерев (`n_estimators=100`).
* Метод оцінки: Дані розділяються на навчальну та тестову вибірки у співвідношенні 80/20. Оскільки це часові ряди, використовується `shuffle=False`, щоб модель не «заглядала в майбутнє» під час навчання.

3. Структура та організація проєкту

Хоча наразі весь код знаходиться в одному файлі, логічно він розділений на три рівні. Якби ви розгортали це як професійний застосунок, структура виглядала б так:

Файлова структура (рекомендована):

* `app.py`: Головний файл із інтерфейсом Streamlit та логікою (ваш поточний код).
* `weather_daily.csv`: Тимчасовий файл, який створюється після завантаження даних (кешування).
* `requirements.txt`: Список бібліотек (`streamlit`, `pandas`, `scikit-learn`, `requests`).

Послідовність дій (Workflow):

1. Конфігурація (Sidebar): Користувач вводить координати (широту/довготу). Програма автоматично обчислює період за останній рік.
2. ETL (Extract, Transform, Load):
* Функція `fetch_weather_data` робить запит до API.
* Дані перетворюються у Pandas DataFrame.
* Створюється ознака `is_precip` (факт опадів сьогодні).


3. Preprocessing (Підготовка):
Функція `process_and_train` створює зміщення (`shift(-1)`), щоб модель вчилася на сьогоднішніх даних передбачати завтрашній стан.


4.Training & Evaluation (Навчання):
* Модель тренується на 80% даних.
* На 20% даних перевіряється точність (Accuracy) та генерується звіт (Precision/Recall).


5. Inference (Прогноз):
* Модель бере останні відомі дані з таблиці.
* Обчислює ймовірність опадів (`predict_proba`).


6. Visualization (Візуалізація):
* Виведення результату (дощ/сонце).
* Побудова стовпчикової діаграми важливості факторів (наприклад, що більше вплинуло на прогноз: вітер чи температура).
